# Found in Pi

Numerical-pattern exploration in the first one million decimal digits of pi, with a simple pattern-length classifier.

## Source and report
- `Found_in_Pi_Final_Polished.ipynb`: selected local notebook with saved outputs.
- `Found_in_Pi_Final_Polished.html`: exported report and its supporting assets.
- Install the packages in `requirements.txt`, then open the notebook with Jupyter. The notebook fetches its digit dataset from the URL recorded in its code.

This release preserves the existing analysis and outputs; it has not been rerun or independently validated as part of this upload. It does not establish the normality of pi.
